고유한 VPN 연결 식별자
중요: VPN이 연결되었을 때만 접근 가능한 내부 IP 또는 VPN 전용 IP를 입력하세요.
Public IP를 입력하면 VPN이 연결되지 않아도 접속 테스트가 성공할 수 있습니다.
형식: IP주소:포트 (예: 10.0.0.1:443, 192.168.1.100:80)
VPN 연결 상태를 체크하는 주기 (초 단위, 최소 10초, 권장: 60초 이상)
TCP: 포트 연결 테스트 (기본값: 443, 80, 22, 8080 또는 지정된 포트)
PING: ICMP PING 테스트 (방화벽에서 차단될 수 있음)
BOTH: TCP와 PING 모두 체크 (둘 중 하나라도 성공하면 UP)
권장 설정:
• 일반적인 환경: 60초 (1분)
• 중요한 VPN: 30초
• 덜 중요한 VPN: 120초 이상
참고: 시스템은 10초마다 체크 주기를 확인하며, 설정된 주기가 지난 VPN만 체크합니다.
VPN 상태 변경 알림 발송 시 사용할 카카오 알림톡 템플릿을 선택하세요. 템플릿은 카카오 템플릿 관리에서 등록할 수 있습니다.
템플릿 변수:
카카오 템플릿 테스트
카카오 템플릿을 선택하고 VPN을 저장한 후 템플릿 테스트가 가능합니다.
