목록으로
Aligo 관리자 페이지에서 확인한 템플릿 코드를 입력하세요
템플릿에 사용되는 변수 목록을 입력하세요.
JSON 배열 형식: ["변수1", "변수2"] 또는 쉼표 구분: 변수1, 변수2
알리고에 등록된 템플릿 본문 형태를 입력하세요.
변수는 #{변수명} 형식으로 입력하세요. 예: #{시스템}, #{알림}
템플릿에 사용되는 버튼 정보를 JSON 형식으로 입력하세요.
예시: {"button":[{"name":"채널추가","linkType":"AC","linkTypeName":"채널 추가"}]}
linkType: AC (채널 추가), AL (앱링크), DS (배송조회), BK (봇 키워드), MD (메시지 전달), WL (웹링크)
