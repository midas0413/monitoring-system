알림 규칙
📝 사용 가능한 변수 (${변수명} 또는 {변수명} 형식 사용)
📋 Rule 정보
  • ${ruleName} - Rule 이름
  • ${ruleId} - Rule ID
  • ${monitoringType} - 모니터링 타입 (SHELL, DB, LOGS, DISK_SPACE)
  • ${alertOperator} - 알림 연산자 (RUN_FAILED, OUTPUT_NUM_GT 등)
🖥️ 서버 정보
  • ${serverId} - 서버 ID
  • ${serverName} - 서버명
  • ${serverHost} - 서버 호스트 (IP 또는 도메인)
  • ${serverTimezone} - 서버 타임존 (예: Asia/Seoul)
📊 실행 결과
  • ${success} - 실행 성공 여부 (true/false)
  • ${status} - 실행 상태 (SUCCESS/FAIL/UNKNOWN)
  • ${output} - 출력 내용 (전체)
  • ${error} - 에러 메시지 (실패 시)
🔢 출력 값
  • ${outputNum} - 출력에서 추출한 숫자 값
  • ${outputLen} - 출력 길이 (문자 수)
⚙️ 임계값
  • ${threshold} - 임계값 (thresholdNum 또는 thresholdLen)
  • ${thresholdNum} - 숫자 임계값
  • ${thresholdLen} - 길이 임계값
  • ${pattern} - 패턴 (정규식 또는 포함 문자열)
⏰ 모니터링 시각
  • ${startedAt} - 시작 시간 (UTC, yyyy-MM-dd HH:mm:ss)
  • ${finishedAt} - 종료 시간 (UTC, yyyy-MM-dd HH:mm:ss)
  • ${startedAtLocal} - 시작 시간 (현지 시각, yyyy-MM-dd HH:mm:ss)
  • ${finishedAtLocal} - 종료 시간 (현지 시각, yyyy-MM-dd HH:mm:ss)
  • ${startedDate} - 시작 날짜 (현지 시각, yyyy-MM-dd)
  • ${finishedDate} - 종료 날짜 (현지 시각, yyyy-MM-dd)
  • ${startedTime} - 시작 시간 (현지 시각, HH:mm:ss)
  • ${finishedTime} - 종료 시간 (현지 시각, HH:mm:ss)
  • ${durationMs} - 실행 시간 (밀리초)
  • ${duration} - 실행 시간 (가독성 형식: X시간 Y분 Z초)
💡 팁: 현지 시각 변수(${finishedAtLocal}, ${startedAtLocal} 등)는 서버에 설정된 타임존을 기준으로 자동 변환됩니다. 예: 서버 타임존이 "Asia/Seoul"인 경우, UTC 시간이 한국 시간으로 변환되어 표시됩니다.
